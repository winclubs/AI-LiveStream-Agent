# 本地直播九项可靠性缺口全部闭合

当前代码已关闭前一份报告中的 9 个非安全问题：商品画层进入虚拟摄像头与 MJPEG，竖屏保持比例，并发开播与退款收敛为单赢家。跨场订单重放不改写当前场统计，音频在媒体 await 后复核代际，容器解码失败不再退化为裸 PCM。上传 CPU 工作已移至统一有界 worker，初始化失败也进入完整清理路径。Watch for: 本轮未发现至少达到 likely 置信度的当前非安全阻断项。

**Verdict**: PASS

## High-level view

发布帧先合成优惠券、商品特写和尺码表，再分发给虚拟摄像头与 JPEG 预览；虚拟摄像头使用保持宽高比的 letterbox。

直播启动以生命周期锁串行化完整状态转换。退款以 `completed -> refunded` 条件更新决定唯一赢家，只有赢家回补库存并写流水。

历史场聚合只作为幂等重放响应返回，运行态统计仅在聚合场次等于当前场时更新。音频代际贯穿媒体、虚拟音频和浏览器输出，容器音频必须通过容器解码。

文档提取、RAG 分块/向量/索引、音色特征和人脸检测通过容量 4、线程数 2 的 worker 调度。lifespan 的外层 `finally` 覆盖服务锁写入和初始化异常。

## 商品画层共享虚拟摄像头与 MJPEG 发布帧

`MuseTalkMediaDriver._publish_frame` 在分发前调用 `compose_scene_overlays`。测试确认优惠券、特写和尺码表改变帧像素，并确认虚拟摄像头帧与 `latest_jpeg_frame` 解码预览都包含画层（`server/adapters/media/musetalk_driver.py:299-310`，`server/tests/test_product_context_and_overlays.py:142-292`）。

`letterbox_frame` 按较小缩放比居中填充目标画布。测试同时覆盖纯函数输出与 `send_frame` 提交给摄像头设备的帧，竖屏内容未改变比例（`server/core/media/virtual_cam.py:26-52,101-109`）。

## 开播与退款由单赢家状态转换收敛

`/live/start` 持有 `global_live_controller.lifecycle_lock` 执行完整 `_start_live_unlocked`，覆盖重复检查、starting 提交、资源启动和 live 提交。并发测试扩大旧竞争窗口后得到一个 200、一个 409，数据库仅保留赢家的一条活动记录（`server/routes/live.py:882-974`，`server/tests/test_business_reliability.py:219-263`）。

退款通过 `WHERE id = ? AND status = completed` 抢占状态；竞争者在 `rowcount != 1` 时回滚，库存加法和 refund 流水只在赢家分支。两个请求完成初始读取后，测试验证一次回补、一条退款流水和一个 refunded 订单（`server/routes/live.py:1497-1527`，`server/tests/test_business_reliability.py:266-334`）。

## 历史 external_id 重放与当前场统计隔离

幂等命中会计算原订单场次的响应值，但 `_refresh_order_stats` 仅在 session_id 等于当前控制器场次时写运行态 stats。跨场测试验证重放返回场 A 聚合，而 `/live/stats` 保持场 B 的 7 元和 1 单（`server/routes/live.py:1365-1405`，`server/tests/test_business_reliability.py:337-383`）。

## 音频代际与严格解码覆盖输出边界

`_speak_sentence` 在媒体驱动 await 返回后重新检查 audio/session 双代际；媒体驱动和虚拟音频也拒绝迟到生产者。测试在 `feed_audio_chunk` 内暂停并触发打断，恢复后没有物理播放或浏览器音频包（`server/routes/live.py:700-791`，`server/tests/test_audio_reliability.py:214-334`）。

声明容器的 soundfile 解码失败直接返回 `(None, 0)`，未知数据也不会进入 raw PCM。故障注入覆盖 MP3、WAV、OGG、FLAC，并确认只有显式 `pcm_s16le` 或 `allow_raw_pcm=True` 可使用裸 PCM（`server/core/media/audio_decode.py:28-77`，`server/tests/test_audio_reliability.py:337-363`）。

## 有界 CPU worker 覆盖上传重计算路径

知识提取、RAG 分块/向量/索引、音色预算与特征、头像像素校验与人脸检测均调用 `run_cpu_bound`（`server/routes/knowledge.py:111-120`，`server/core/rag/engine.py:446-484`，`server/routes/voices.py:88-105`，`server/routes/avatars.py:71-84`）。并发测试验证活动线程不超过 2、接纳任务不超过 4、工作不在事件循环线程执行，并覆盖取消与满载等待（`server/core/cpu_worker.py:14-90`，`server/tests/test_cpu_worker.py`）。

## 初始化异常共享完整清理路径

lifespan 的外层 `try/finally` 包住服务锁写入和全部初始化。初始化失败后会独立尝试停止控制器、关闭虚拟音频、dispose 数据库、删除同 PID 服务锁并 flush 日志；测试还覆盖服务锁写入本身失败（`server/app.py:42-108`，`server/tests/test_operations.py:106-190`）。
