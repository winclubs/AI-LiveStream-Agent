⚡ MOSS-TTS-Nano 端侧原生零样本克隆流程：
① 上传一段 10~30 秒 的清晰真人人声录音（WAV/MP3，无背景音乐、无混响、口距稳定）——样本质量直接决定克隆相似度；
② 系统以您的录音为声学条件全新合成台词，GPU 可用时自动独显加速、否则多线程 CPU 运算，免 Key 开箱即用。
⚠️ 诚实说明：端侧 100M 轻量模型可保留 音高与韵律特征，但 音色相似度存在上限（无法做到百分百复刻）。对音色相似度要求极高的商业场景，推荐切换 （大模型云端声纹复刻，相似度显著更高）。
