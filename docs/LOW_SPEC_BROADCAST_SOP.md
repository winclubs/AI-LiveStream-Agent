## 1. 系统核心破局原理 (为什么低配机也能开播)

在传统数字人直播中，低配电脑面临三大死穴：
1. **显存 OOM 崩溃**：本地加载数字人生成模型需 8GB~24GB 显存，轻薄本核显直接闪退；
2. **虚拟摄像头被风控拉黑**：抖音直播伴侣、快手伴侣对 OBS Virtual Camera 等虚拟摄像头插件严格封禁降权；
3. **CPU 飙到 100% 导致音频断续**：模型运算挤占 CPU，导致主播说话破音、吞字、画面 PPT。

**本系统的破局设计**：
```
       ┌────────────────────────────────────────────────────────┐
       │                 低配机核心工程破局四重奏                 │
       └───────────────────────────┬────────────────────────────┘
                                   │
      ┌────────────────────────────┼────────────────────────────┐
      ▼                            ▼                            ▼
【原生视窗捕获】             【算力端云解耦】             【自适应防爆音看门狗】
伴侣直读窗口句柄             高算力放云端A100             CPU超限自动降频至16FPS
100%合规，杜绝封号           本地轻薄本0显存              音频线程最高优先级保护
```

## 2. 开播方案二选一：端云分离 vs 纯本地轻量

### 方案 A（首推·影院级画质）：端云分离 Sidecar 模式
* **成本**：每小时仅约 1.5 ~ 3 元人民币（各大 GPU 云平台按秒计费，随开随停）；
* **画质表现**：1080P 高清真人口型，30FPS 满帧流畅，毛发纹理清晰；
* **本地负载**：本地轻薄本 CPU 占用 $< 10\%$，显卡占用 $0\%$，机身冰凉不发烫。

#### 四步极速连接云端：
1. **租用云端 GPU 实例**：
   - 登录任意 GPU 算力平台（如 AutoDL、揽睿星舟、RunPod 等）；
   - 选择配备 **RTX 3090 / 4090 / A100 / V100** 的基础镜像（Ubuntu 20.04/22.04 + PyTorch 2.x）。
2. **在云主机执行一键部署脚本**：
   在云端终端执行项目内置的一键引导命令：
   ```bash
   python3 scripts/cloud_sidecar_bootstrap.py
   ```
   *脚本会自动完成 GPU 显存探测、自适应端口配置并启动 Cloudflare 免费穿透隧道。*
3. **获取安全公网 WebSocket 地址**：
   终端会输出类似于以下的公网直连地址：
   ```text
   ======================================================================
   🚀 Cloudflare 穿透成功！端云通信隧道已建立：
   👉 WebSocket 地址: wss://lucky-bear-xxxx.trycloudflare.com/ws/render-v3
   ======================================================================
   ```
4. **在中控台填入并点亮通信**：
   - 打开本地管理后台 `http://localhost:8000`；
   - 点击顶部【⚙️ GPU 与云端配置】面板；
   - 在【远程 WebSocket 地址】中粘贴上述 `wss://...` 地址；
   - 点击【⚡ 测试连接并保存】，右侧状态显示绿色“已连接 (RTT: 35ms)”，即代表链路打通！

### 方案 B（完全免费·零成本）：纯本地免显卡轻量切流模式
* **成本**：0 元；
* **硬件要求**：任何具有 4 核 CPU、4GB 内存的旧电脑即可；
* **工作机制**：
  - **待机非发言阶段**：后台无缝循环播放 1080P 真人呼吸微动作视频，CPU 占用 $< 3\%$；
  - **发言带货阶段**：系统采用纯 CPU 标准数学矩阵的唇形渲染管线（Viseme 引擎），不需要任何 CUDA 显卡，普通 CPU 轻松稳定 25FPS 满帧运行。

## 3. 三大直播伴侣窗口捕获与色度抠图实操指引

> ⚠️ **红线禁忌**：**绝对不要在伴侣中使用“虚拟摄像头（Virtual Camera）”来源！**  
> 必须使用伴侣自带的**【窗口捕获】**直读数字人视窗。

### 第一步：唤起独立原生绿幕视窗
1. 本地启动服务：`python server/app.py`；
2. 启动视窗：
   - **方式 1**：在后台【直播大屏】上方直接点击 **【🎥 独立绿幕视窗】** 按钮；
   - **方式 2**：在浏览器新建窗口打开 `http://localhost:8000/avatar-viewport`；
3. 打开后将视窗调整到合适大小，或**双击画面任意位置进入无边框全屏**；
4. 默认背景为标准纯色绿幕（Hex `#00FF00`）。若直播间主体服装有绿色元素，可点击顶部控制岛切换为“纯黑”或“纯蓝”背景。

---

### 第二步：抖音直播伴侣配置
1. 打开【抖音直播伴侣】客户端；
2. 点击左下角【添加素材】 ➔ 选择【窗口】；
3. 在【选择窗口】下拉列表中，找到并选中 **`数字人高清渲染视窗 · 专供直播伴侣窗口捕获`**；
4. 捕获方式选择【自动】或【Windows Graphics Capture】，点击确定；
5. **开启绿幕抠图**：
   - 在图层列表中选中该窗口，点击上方或右键菜单中的【抠图】/【滤镜】；
   - 勾选开启【色度抠图】；
   - 关键颜色选择【绿色】（系统默认 `#00FF00`）；
   - **参数推荐调优**：
     - **相似度**：`38 ~ 42`（直到绿色背景完全变为透明）；
     - **平滑度**：`15 ~ 20`（消除边缘羽化噪点）；
     - **溢出抑制**：`25 ~ 30`（消除人物发丝和脸颊边缘的微弱绿光反射）；
6. 在数字人图层下方添加【图片】或【视频】作为直播间带货背景（货架、专柜海报、促销滚动条等）；
7. 调整数字人图层的大小和在画面中的站位（左侧或居中），在右下角预留出抖音小黄车商品卡片位置。

---

### 第三步：快手直播伴侣配置
1. 打开【快手直播伴侣】客户端；
2. 点击上方【添加画面】 ➔ 选择【窗口捕获】；
3. 目标窗口选择【数字人高清渲染视窗】；
4. 勾选【开启色键/抠像】，类型选择【绿幕抠图】；
5. 拖动【色键相似度】滑块至背景透光，微调【边缘羽化】确保边缘平滑；
6. 将数字人图层锁定，叠加促销挂件与商品背景图。

---

### 第四步：微信视频号直播助手配置
1. 打开微信桌面端【视频号直播助手】；
2. 在主界面场景中点击【添加画面源】 ➔ 选择【窗口】；
3. 选定数字人视窗；
4. 属性面板中开启【绿幕抠像】，关键色设定为绿色；
5. 调整图层层级（数字人置于背景之上、商品组件之下），完成画面合成。

## 4. 音频路由与防爆音配置规范

为了让直播伴侣能够清晰接收到 AI 数字人的语音，同时避免电脑系统提示音混入直播间，建议配置虚拟音频直连通道：

### 1. 虚拟声卡配置（推荐 VB-Audio Cable，永久免费）
- 下载并安装 [VB-Audio Virtual Cable](https://vb-audio.com/Cable/)；
- 安装完成后，Windows 会新增一个名为 `CABLE Input (VB-Audio Virtual Cable)` 的音频设备。

### 2. 软件与伴侣对接
1. **数字人系统端**：
   - 在中控台【⚙️ 系统设置】中，将“音频输出设备”选择为 `CABLE Input`；
2. **直播伴侣端**：
   - 在抖音/快手直播伴侣的【声音设置】中，添加一个麦克风/音频输入源；
   - 设备选择 `CABLE Output (VB-Audio Virtual Cable)`；
   - 此时数字人的语音将通过内录专线无损直达直播伴侣，观众听到的音质极其清晰纯净！

### 3. 内核级音频防爆音兜底机制
系统已内置 Windows 内核优先级调度守护：
- 播放线程自动绑定操作系统最高调度优先级（`THREAD_PRIORITY_HIGHEST`）；
- 宿主机出现瞬时 CPU 飙升时，系统会优先把算力留给音频流水线；
- 配合系统看门狗自动将画面从 25FPS 降至 16FPS，确保声音绝对不卡、不吞字、无电音杂音。

1. **平台选择**：在下拉框中选择当前开播的平台（`抖音`、`快手`、`微信视频号` 或 `B站`）；

## 6. 常见突发问题应急排查表 (FAQ)

### Q1: 伴侣添加“窗口捕获”后显示黑屏怎么办？
- **原因**：部分 Windows 显卡加速机制导致浏览器硬件加速遮挡。
- **解法**：
  1. 在浏览器设置中，搜索并关闭【使用图形加速 (硬件加速)】，重启浏览器；
  2. 在直播伴侣的窗口捕获属性中，将【捕获方式】由“自动”更改为“Windows 10 / 11 Graphics Capture”；
  3. 双击视窗画面确保其处于活动显示状态。

### Q2: 绿幕扣完后人物边缘有一圈淡淡的绿光怎么办？
- **解法**：在直播伴侣的色度抠像设置中，适当调高**【溢出抑制】（Spill Suppression）**数值至 `30 ~ 35`，该选项会智能中和发丝和肩部的反射光线，让边缘色彩浑然一体。

### Q3: 电脑风扇狂转，会不会突然把直播间卡死？
- **不用担心**：系统内置了 `SystemResourceWatchdog` 看门狗：
  - 当 CPU 负载超过 85% 时，系统会自动从 25FPS 降频至 16FPS，立即释放 36% 运算资源让给音频和推流；
  - 负载回落后会自动平滑回升，整个过程观众端完全无感，声音始终丝滑流畅。

### Q4: 怎样验证开播链路是否全部健康？
在本地终端运行一键自检脚本：
```bash
python scripts/verify_broadcast_pipeline.py
```
若全部显示 `[✅ PASS]`，代表从绿幕视窗、降频看门狗、多平台弹幕、电商提权到端云 Sidecar 全部就绪，随时可以放心开播！
