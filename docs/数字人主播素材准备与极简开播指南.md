## 📋 一、ByteDance LatentSync 官方素材规格对照表

| 核心维度 | 官方手册规范 (LatentSync Specification) | 本项目实战最佳推荐 (Live Stream Standard) | 常见错误与避坑禁忌 |
| :--- | :--- | :--- | :--- |
| **视频时长** | 官方以 5~10 秒切片对齐特征，无技术硬上限 | **30 秒 ~ 1 分钟（最长支持 2 分钟）** | ❌ 视频小于 10 秒（导致动作单调机械）<br>❌ 视频超过 3 分钟（增加云端传输与切片处理负担） |

| **拍摄角度 (视线)** | 保持在 $\pm 20^\circ$ 内，尽量正对相机 | **水平视线直视镜头**，双眼平视，头部正向 | ❌ 仰拍/俯拍（下颌畸变变形）<br>❌ 侧脸大于 30°（导致嘴角羽化边缘撕裂） |

| **是否真人说话？** | **核心为下半脸扩散掩码重绘 (Mouth Inpainting)** | **【黄金铁律】绝对不要开口说话！全程自然微笑闭唇** | ❌ **录制时真人开口说话（致命翻车）**：会导致原片说话动作与 AI 新语音打架，出现双重嘴唇叠影与下巴抽搐。 |
| **画面帧率 (FPS)** | **强制必须 25 FPS** (官方预处理强制 resample) | **固定 25 FPS 恒定帧率**录制 | ❌ 30fps / 60fps / 可变帧率 VFR（导致音画时序微偏差与抽帧抖动） |
| **视频分辨率** | 1.5 内部处理 256px，1.6 内部扩展至 512px | **1080P 竖屏 (1080×1920)** 或 **横屏 (1920×1080)** | ❌ 720P 以下低清视频（面部马赛克或噪点过高） |
| **光照与遮挡** | 均匀柔光，人脸无浓烈阴影，无遮挡物 | **打亮面部柔光 + 发丝轮廓光**，背景平整 | ❌ 伸手遮挡嘴部、戴口罩、长刘海遮眼遮唇 |

## 🎬 二、为什么录制时“绝对不要开口说话”？（物理原理解析）

很多新手最大的困惑是：*“既然要数字人说话，为什么录视频时真人不能说话？”*

```
【错误录制：真人边说话边录制】
原视频画面：真人张大嘴喊“大家好” (下巴被大幅拉长，嘴唇张开露齿)
                                   +
AI 此时要说：“欢迎来到直播间”中的“欢” (双唇微拢呈闭合/微圆口型)
                                   ▼
【严重车祸】：AI 试图在原片“大张的下巴”上重绘“微拢的嘴”，边缘产生双重嘴唇、牙齿外露叠影、下巴剧烈抽搐！

【正确录制：真人纯动作微笑闭唇】
原视频画面：面带自然亲和微笑，嘴唇轻柔微合，下颌处于自然平衡生理状态
                                   +
AI 语音驱动：根据实时音频，精准驱动下颌开合、唇形拉伸、自然露齿吐字
                                   ▼
【影视级拟真】：发丝、眼神、身体微动来自原片，嘴部完全由 AI 实时平滑驱动，边缘天衣无缝！
```

## 📐 三、机位与景别实操设置建议

1. **相机距离与高度**：
   - 手机或微单放置在与主播**双眼平齐的高度**（避免高机位俯拍脸显小下巴畸变，也避免仰拍露出鼻孔）；
   - 人距相机约 **1.5 米 ~ 2 米**，使用 35mm~50mm 等效焦段，避免广角镜头引起的桶形畸变。
2. **主播与绿幕距离**：
   - 主播距背后绿幕至少 **1.2 米 ~ 1.5 米**；
   - 严禁背贴绿布（会导致绿色反光映射到主播头发丝和耳郭边缘，造成 OBS 抠像发黑发虚）。
3. **肢体动作幅度**：
   - 保持日常直播的自然呼吸起伏和亲和微笑；
   - 身体微幅晃动完全正常且更逼真，但**严禁大幅度突然转身、剧烈甩头**；
   - 肢体手势保持在胸部下方，**严禁手掌伸到嘴唇前方**遮挡下半脸。

## 🚀 四、极简 3 步开播指南（从素材到开播）

```
[步骤 1: 录制 30秒~1分钟 绿幕视频] ──> [步骤 2: 主播管理点击【🎬 制作数字人】上传] ──> [步骤 3: 连麦开播]
 (20s~120s 均可 · 全程闭口中景)        (系统自动检测人脸、截取切片、提取 coords)          (OBS/抖音直播伴侣无缝推流)
```

1. **步骤 1：建立主播档案**
   - 进入控制台【主播管理】，点击“+ 新建主播”，输入姓名并绑定适合的音色，保存档案。
2. **步骤 2：上传出镜视频（一键制作数字人）**
   - 在主播列表中，点击对应主播右侧的 **【🎬 制作数字人】**（或【🔄 重新制作】）；
   - 选择您录制好的 **30秒~1分钟（20秒~120秒均可，随意时长）** 绿幕出镜 MP4 视频，点击上传；
   - 系统将自动执行：**25fps 视频对齐 $\rightarrow$ 人脸关键点检测 $\rightarrow$ 高清面部裁切 $\rightarrow$ 姿态坐标索引提取**。
3. **步骤 3：音画联动与试播验证**
   - 点击 **【🔊 试听发音】**，监视舱将调用 LatentSync 神经网络进行实时音唇驱动验证；
   - 确认口型咬合自然、眨眼稳定后，即可启动直播推流！

## 🛡️ 五、OBS Studio 色度键最佳抠像推荐参数

若使用 OBS 进行绿幕背景替换与贴片叠加，请为数字人视频源添加 **【色度键 (Chroma Key)】** 滤镜，填入以下参数：

- **关键颜色类型**：绿色 (`Green`)
- **相似度 (Similarity)**：`400`
- **平滑 (Smoothness)**：`80`
- **主溢出减少 (Key Spill)**：`100`
- **不透明度**：`100%`
- **对比度 / 亮度 / 伽玛**：保持默认 `0.00`
