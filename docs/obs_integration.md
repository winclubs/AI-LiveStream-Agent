# OBS Studio 与直播伴侣协同集成指南

本文档指导主播团队与技术人员如何将 **AI-LiveStream-Agent** 的画面、声音与互动流对接到 **OBS Studio**、**抖音直播伴侣**、**快手直播伴侣** 或 **Bilibili 直播姬** 中。

---

## 1. 架构与接入方案对比

AI 直播引擎主要通过两种方式将生成的数字人头像、动画与语音注入到直播推流软件中：

```
+--------------------------------------------------------+
|               AI-LiveStream-Agent 引擎                  |
|  (FastAPI / WebSocket / 状态机 / 文本生成 / 语音合成)    |
+--------------------------------------------------------+
           |                                  |
   [方案 A: 浏览器源(推荐)]            [方案 B: 虚拟设备]
           |                                  |
           v                                  v
+------------------------+        +--------------------------+
|  OBS 浏览器源           |        | OBS 视频采集(虚拟摄像头)  |
|  (画面透明、音频同传)   |        | + 音频输入(VB-CABLE)     |
+------------------------+        +--------------------------+
           \                                  /
            \                                /
             v                              v
      +-------------------------------------------+
      |  OBS / 直播伴侣 主画布合成 (商品、背景、弹幕) |
      +-------------------------------------------+
                            |
                            v
                     RTMP / 平台推流
```

| 特性指标 | 方案 A：OBS 浏览器源（推荐） | 方案 B：虚拟音视频设备 |
| :--- | :--- | :--- |
| **接入难度** | 简单（直接输入 URL，无需驱动） | 中等（需安装虚拟摄像头与虚拟声卡） |
| **透明通道 (Alpha)** | **完全支持**（透明背景自然融入任意底图） | 不支持（绿幕扣像易产生毛边） |
| **音画同步性** | 极佳（音频与视频共用同一个网页渲染上下文） | 取决于两套虚拟驱动的时间戳对齐 |
| **推荐适用** | 绝大多数常规直播、电商带货、互动娱乐 | 需使用专业调色滤镜、复杂硬件切换台 |

## 2. 方案 A：OBS 浏览器源接入 SOP（强烈推荐）

### 2.1 添加数字人画面源
1. 打开 OBS Studio，在目标场景的 **来源 (Sources)** 列表中，点击 `+` 号并选择 **浏览器 (Browser)**。
2. 命名为 `AI-Avatar-Stream`，点击确认进入属性窗口：
   * **URL**：输入数字人画面服务地址（默认为 `http://127.0.0.1:18080/avatar/stream`，控制台可在顶部导航复制）。
   * **宽度 (Width)**：`1080`（若为手机竖屏直播）或 `1920`（电脑横屏）。
   * **高度 (Height)**：`1920`（竖屏）或 `1080`（横屏）。
   * **自定义帧率 (FPS)**：勾选并设置为 `30` 或 `60`。
   * **自定义 CSS**：清空默认的 `body { background-color: rgba(0, 0, 0, 0); margin: 0px auto; overflow: hidden; }`，确保背景完全透明。
   * **通过 OBS 控制音频 (Control audio via OBS)**：**务必勾选**。勾选后，OBS 的“混音器”中会出现此源的独立音量条，方便直接监听与调控电平。
   * **场景激活时刷新浏览器**：建议勾选。
3. 点击“确定”，即可在 OBS 画布中看到数字人。拖拽缩放并放置在直播间合适层级。

## 3. 方案 B：虚拟摄像头与虚拟声卡接入（可选）

如果使用的是不支持嵌入网页源的特定直播伴侣，或者需进行外部降噪调色：

### 3.1 视频接入（虚拟摄像头）
1. 安装可选媒体依赖：
   ```powershell
   python -m pip install -r server/requirements-optional.txt
   ```
2. 启动 OBS Studio 内置的 **虚拟摄像机 (Start Virtual Camera)** 或使用第三方虚拟摄像头驱动。
3. 在服务配置中开启虚拟摄像头推流输出。
4. 在直播伴侣中添加 **摄像头/视频采集设备**，选择对应的虚拟摄像头名称。

### 3.2 音频接入（虚拟声卡路由）
1. 下载并安装免费的 **VB-CABLE Virtual Audio Device**。
2. 将 AI 引擎的音频输出目标设备设置为 `CABLE Input (VB-Audio Virtual Cable)`。
3. 在 OBS / 直播伴侣的“音频输入采集”中，选择 `CABLE Output (VB-Audio Virtual Cable)`。

## 4. 音画同步（A/V Sync）精准调谐

数字人的嘴型、表情与 TTS 音频如果在推流时存在延迟差，会给观众带来“对不上嘴型”的违和感。

### 4.1 延迟影响因子
1. **TTS 合成耗时**：语音生成首包延迟。
2. **渲染后端缓冲**：帧缓冲队列造成的轻微画面延后。
3. **OBS 编码缓冲区**。

### 4.2 调校步骤
1. **准备测试音视频**：
   在控制台的 **互动调试** 页面发送包含明显音画特征的测试文本（例如：“3、2、1，拍手！”并在拍手瞬间触发画面动作）。
2. **录制本地片段**：
   在 OBS 中点击 **开始录制**，执行上述测试，录制 10 秒后停止。
3. **使用播放器或剪辑工具逐帧分析**：
   * **情况 A：画面比声音慢（嘴型跟不上声音）**：
     * 在 OBS **混音器** 中，点击对应的数字人音频源齿轮图标 -> **高级音频属性 (Advanced Audio Properties)**。
     * 将该音频源的 **同步偏移 (Sync Offset)** 增加相应的毫秒数（例如 `+150 ms`），让声音推迟播放以对齐画面。
   * **情况 B：声音比画面慢（声音落后于嘴型）**：
     * 通过环境变量 `LIVE_AGENT_AV_DELAY_MS` 进行系统级前置补偿：
       在服务启动前设置：
       ```powershell
       $env:LIVE_AGENT_AV_DELAY_MS = "100"  # 根据实际偏差数值微调
       ```
4. 重新录制，直至在 2-3 帧（~60-100ms）以内完全对齐。

## 5. 开播前 5 步冒烟检查清单 (Pre-flight Checklist)

每次开播前，请值班运营或主播逐一确认以下项目：

* [ ] **1. 服务状态检查**：访问 `http://127.0.0.1:18080/readyz`，确认返回 HTTP 200 且 `status: "ready"`。
* [ ] **2. OBS 混音器电平**：触发一段主播介绍，确认 OBS 中数字人音轨有正常的绿色/黄色电平波动，监听耳机中声音清晰、无爆音、无爆流。
* [ ] **3. 画面清晰度与位置**：确认数字人透明背景无黑边，图层位于商品介绍与背景板之上、弹幕互动框之下。
* [ ] **4. 互动链路连通性**：在控制台测试发送一条弹幕互动，观察数字人是否在 1~2 秒内产生状态机切换、回复与动作反应。
* [ ] **5. 推流码率与丢帧**：在 OBS 中开启推流，观察右下角状态栏：丢帧率为 0.0%、网络状态指示为绿色、CPU 占用处于健康范围（建议不超过 70%）。
